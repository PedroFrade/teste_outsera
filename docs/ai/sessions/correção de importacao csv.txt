● Um CSV de 0 bytes, ou só com linhas em branco, agora faz o startup falhar. A
  mensagem é CSV file has no header (expected:
  year;title;studios;producers;winner): <caminho>. Typecheck, lint, prettier e
  os 69 testes passam. Sem a correção, o teste novo falha.

  Causa: o csv-parse só chama o callback columns quando há ao menos um registro.
  Com arquivo vazio, a checagem das colunas obrigatórias nunca rodava, e o
  arquivo parecia um CSV válido sem linhas.

  Correção: csv-reader.ts (src/importer/csv-reader.ts) marca quando o cabeçalho
  foi lido. Se o arquivo termina sem ele, readCsv lança CsvImportError, como já
  acontece com coluna faltando. O aviso "has a header but no data rows" passa a
  valer só para arquivo que tem cabeçalho de verdade.

  Decisão para você revisar: escolhi falhar o startup em vez de só corrigir o
  texto do warn. Sem cabeçalho não dá para saber se é o arquivo certo, e subir a
  API com resultados vazios esconderia um upload truncado. A D18 (CSV só com
  cabeçalho sobe com warn) continua valendo e foi anotada como restrita a
  arquivos com cabeçalho. Se preferir manter o warn, a mudança é só a mensagem.
